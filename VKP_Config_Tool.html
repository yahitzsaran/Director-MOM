Where to find your values

Go to supabase.com → your project → Settings (gear icon) → API
• Project URL — looks like https://abcxyz.supabase.co
• Anon Key — the long key under "Project API Keys" → anon public
Copy exactly from Supabase → Settings → API → Project URL
Copy the anon / public key (starts with eyJ…). Do NOT use the service_role key.
✓ File downloaded!
Now upload VKP_MOM_App_Configured.html to your hosting.
That's it — open it in browser and sign in.
After uploading, also do this in Supabase:
1
Go to Authentication → URL Configuration → set Site URL to your domain
2
Add your domain to Redirect URLs (e.g. https://yourdomain.com)
3
Sign in → then in Supabase SQL Editor make yourself admin:
update public.profiles set role='admin' where id=(select id from auth.users where email='your@email.com');
